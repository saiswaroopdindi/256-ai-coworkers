Approval-aware agent trace

Write a Python function that returns READY, AWAITING_APPROVAL, EXECUTING, SUCCEEDED, or FAILED. Reject external side effects without approval and record a trace event.

Success criteria → explicit state transition, no side effect before approval, useful error message, and one retryable failure.

Interactive challenge · system design
